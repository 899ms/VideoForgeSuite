# VibeCoding 宝藏网站合集

> 做UI设计和VibeCoding时的灵感来源、模板库、工具网站合集。

## 一、灵感与参考网站

### 1. Awwwards
- **定位**：全球最佳网页设计奖，收录最顶级的网站设计
- **用途**：找灵感、看动效、学布局
- **特点**：每个获奖网站都有详细的设计分析
- **适用场景**：做高端官网、品牌站、创意网页时参考

### 2. Dribbble
- **定位**：设计师社区，UI/UX设计作品分享
- **用途**：找UI组件灵感、配色参考、布局参考
- **特点**：作品质量高，分类细致
- **适用场景**：做APP界面、后台系统、移动端设计时参考

### 3. Behance
- **定位**：Adobe旗下设计社区，完整项目展示
- **用途**：看完整项目流程、品牌设计、动效设计
- **特点**：项目完整，有设计思路说明
- **适用场景**：做品牌设计、完整项目、动效短片时参考

### 4. SiteInspire
- **定位**：网页设计灵感库，按风格/类型/配色分类
- **用途**：快速找到特定风格的网站参考
- **特点**：分类细致，可以按配色搜索
- **适用场景**：需要特定风格参考时快速查找

## 二、模板与组件库

### 1. 900+高级网页模板（抖音推荐）
- **定位**：AI生成的高级网页模板集合
- **用途**：直接套用模板，或拆解模板学习布局
- **特点**：模板质量高，覆盖多种行业和风格
- **适用场景**：快速出稿、学习布局结构、参考配色

### 2. Tailwind UI
- **定位**：Tailwind CSS官方组件库
- **用途**：直接复制组件代码，快速搭建界面
- **特点**：组件精美，代码干净，可定制性强
- **适用场景**：用Tailwind做项目时快速搭建

### 3. shadcn/ui
- **定位**：开源React组件库，可复制可定制
- **用途**：直接复制组件源码到项目中
- **特点**：设计现代，代码开源，完全可控
- **适用场景**：React项目、需要高度定制的界面

### 4. Aceternity UI
- **定位**：高端动效组件库，专注VibeCoding风格
- **用途**：复制炫酷动效组件代码
- **特点**：动效丰富，有3D、粒子、视差等高级效果
- **适用场景**：做创意官网、VibeCoding风格网页

## 三、配色工具

### 1. Coolors
- **定位**：快速生成配色方案
- **用途**：按空格键生成随机配色，锁定喜欢的颜色
- **特点**：快速、直观、可导出多种格式
- **适用场景**：快速找配色方案

### 2. Adobe Color
- **定位**：Adobe官方配色工具
- **用途**：用色轮生成配色、从图片提取配色
- **特点**：专业、有配色理论支持
- **适用场景**：需要专业配色时使用

### 3. Khroma
- **定位**：AI配色工具，根据你的喜好学习
- **用途**：选择喜欢的颜色，AI生成配色方案
- **特点**：个性化、AI驱动
- **适用场景**：找不到配色灵感时使用

## 四、动效参考

### 1. Codrops
- **定位**：前端动效教程和演示
- **用途**：学习高级CSS/JS动效实现
- **特点**：教程详细，有完整源码
- **适用场景**：学习复杂动效实现

### 2. CodePen
- **定位**：前端代码社区，动效Demo集合
- **用途**：搜索动效实现，直接复制代码
- **特点**：实时代码预览，社区活跃
- **适用场景**：找特定动效的实现代码

### 3. Motion Trends
- **定位**：UI动效趋势收集
- **用途**：看最新的UI动效设计趋势
- **特点**：按年份/类型分类，有视频演示
- **适用场景**：了解动效趋势，找灵感

## 五、GitHub神级项目（一键复刻）

### 1. 各种UI框架复刻项目
- **定位**：GitHub上开源的高端UI复刻
- **用途**：直接clone项目，学习或修改使用
- **特点**：代码完整，可直接运行
- **适用场景**：学习高端UI实现，快速搭建类似项目

### 2. VibeCoding模板项目
- **定位**：VibeCoding风格的开源模板
- **用途**：基于模板快速开发
- **特点**：动效丰富，设计现代
- **适用场景**：做创意官网、个人作品集

## 使用方法

1. **找灵感**：先看Awwwards/Dribbble，确定想要的风格
2. **找模板**：从模板库找类似的布局，拆解学习
3. **找组件**：从组件库复制需要的UI组件
4. **找配色**：用配色工具生成配色方案
5. **找动效**：从动效参考库找需要的动效实现
6. **组合定制**：把以上元素组合起来，定制成自己的设计

## 应用场景

- 做网页设计时找灵感和参考
- VibeCoding时快速搭建高端界面
- 学习UI设计和动效实现
- 快速出稿，提高设计效率
