# 配色方案库

> 做UI设计和视频制作时的配色方案合集。每套配色3-4种主色，有明确的主色/辅助色/中性色，适用场景明确。

## 第一层：目标层（所有 agent 必须达成）

### 效果目标
选择和使用配色方案时，保证配色统一、协调、有层次，不出现AI味的彩虹色混搭。

### 验收标准
- [ ] 每套配色不超过4种主色
- [ ] 有明确的主色（60%）、辅助色（30%）、强调色（10%）
- [ ] 文字和背景对比度足够（WCAG AA标准，对比度>4.5:1）
- [ ] 配色和内容主题匹配（科技用蓝、自然用绿、温暖用橙）
- [ ] 深色/浅色模式都有对应的配色方案

### 禁止事项
- 禁止彩虹色混搭（超过4种主色）
- 禁止霓虹色混搭（高饱和色堆在一起）
- 禁止渐变文字（AI味重）
- 禁止文字和背景对比度不够（看不清）
- 禁止配色和主题不匹配（比如儿童产品用全黑）

## 第二层：实现层（参考，不强制）

### 配色理论基础

**60-30-10原则：**
- 60%：主色（背景、大面积区域）
- 30%：辅助色（次要区域、卡片、侧边栏）
- 10%：强调色（按钮、链接、重点文字）

**配色方法：**
- **单色配色**：同一色相的不同深浅（最安全，最统一）
- **类比配色**：色轮上相邻的3个颜色（和谐，自然）
- **互补配色**：色轮上相对的2个颜色（对比强，有活力）
- **三色配色**：色轮上等距的3个颜色（丰富，平衡）

### 配色方案合集

#### 方案1：经典科技蓝（适合AI/科技/互联网产品）
```
主色（背景）：#0f172a（深蓝黑）
辅助色：#1e293b（深蓝灰）
强调色：#3b82f6（亮蓝）
文字：#f8fafc（白色）
辅助文字：#94a3b8（浅灰蓝）
```
- **特点**：科技感、专业、冷静
- **适用场景**：AI产品、科技公司官网、数据可视化
- **参考**：Stripe、Vercel、Linear

#### 方案2：温暖橙（适合创意/教育/生活类产品）
```
主色（背景）：#fffbeb（暖白）
辅助色：#fef3c7（浅橙黄）
强调色：#f59e0b（琥珀橙）
文字：#1f2937（深灰）
辅助文字：#6b7280（中灰）
```
- **特点**：温暖、友好、有活力
- **适用场景**：教育产品、生活类APP、创意工作室
- **参考**：Notion、Duolingo、Headspace

#### 方案3：森林绿（适合自然/健康/环保类产品）

```
- **特点**：极简、高级、永恒
- **适用场景**：个人作品集、高端品牌、设计工作室
- **参考**：Apple官网、MUJI、Dieter Rams设计

#### 方案6：深色模式通用（适合所有产品的深色模式）
```
主色（背景）：#0a0a0a（近黑）

文字：#fafafa（近白）
辅助文字：#a3a3a3（浅灰）
```
- **特点**：护眼、高级、聚焦内容
- **适用场景**：所有产品的深色模式、视频背景
- **参考**：GitHub Dark、VS Code Dark、YouTube Dark

#### 方案7：Kurzgesagt风格（适合科普视频/知识讲解）
```
主色（背景）：#1a1a2e（深蓝）
辅助色：#16213e（更深蓝）

辅助文字：#a0a0c0（浅蓝灰）

- **特点**：鲜艳、对比强、有活力
- **适用场景**：科普视频、知识讲解、教育内容
- **参考**：Kurzgesagt视频

#### 方案8：温暖沙色（适合人文/历史/生活类视频）

### 其他配色方法

### 适用场景
- 快速出稿 → 从配色方案库选一套直接用
- 需要独特配色 → 从图片/电影/品牌提取，或AI生成
- 深色模式 → 用方案6，或把浅色方案反转调整

## 使用方法

1. **触发时机**：做UI设计或视频制作，需要确定配色时
2. **操作步骤**：
   - 根据内容主题选择合适的配色方案
   - 确认主色/辅助色/强调色的比例（60-30-10）
   - 检查文字和背景的对比度（>4.5:1）
   - 在实际设计中应用，观察效果
   - 微调颜色（深浅、饱和度），直到满意
3. **输入输出**：
   - 输入：内容主题、风格偏好
   - 输出：完整的配色方案（色值+使用比例+适用场景）
