# AI编程助手UI审美提升指南

> 用AI编程助手（Cursor/Trae/豆包等）做UI时，如何提升审美，做出高级感的界面。核心是：给AI正确的设计语言，而不是让AI瞎猜。

## 第一层：目标层（所有 agent 必须达成）

### 效果目标
用AI编程助手做出具有高级审美、设计统一、动效流畅的UI界面。不是"能用就行"，而是"好看且好用"。

### 验收标准
- [ ] 配色统一（不超过4种主色，有明确的主色/辅助色/中性色）
- [ ] 布局有层次（重要内容突出，次要内容弱化，有呼吸感）
- [ ] 字体有层级（标题/正文/辅助文字大小粗细分明）
- [ ] 间距有规律（用8px网格系统，间距不是随机的）
- [ ] 动效有目的（每个动效都有意义，不是为动而动）
- [ ] 组件风格统一（按钮/卡片/输入框风格一致）
- [ ] 没有AI味元素（渐变文字/发光边框/毛玻璃/霓虹色混搭）

### 禁止事项
- 禁止让AI自由发挥配色（必须指定配色方案）
- 禁止用"好看一点""高级一点"这种模糊指令（必须具体）
- 禁止一次让AI做整个页面（必须分组件、分区域做）
- 禁止不看参考就做（必须先给AI看参考图/参考网站）
- 禁止不迭代就定稿（至少迭代3次，每次聚焦一个维度）

## 第二层：实现层（参考，不强制）

### 原理
AI编程助手的审美问题，本质是**指令问题**。AI不知道什么是"好看"，但如果你给它明确的设计语言（配色、字体、间距、组件风格、参考图），它能做出很好的效果。

核心方法：**用设计师的语言和AI沟通，而不是用普通人的语言。**

### 提升审美的5个步骤

#### 步骤1：先找参考，再做设计
- 不要让AI从零开始做
- 先在Awwwards/Dribbble找3-5个喜欢的参考
- 把参考图给AI看，说"按照这个风格做"
- 分析参考的配色、字体、布局、动效，告诉AI

#### 步骤2：给AI明确的设计系统
不要说"做一个好看的页面"，要说：
```
配色：主色#2563eb（蓝），辅助色#f59e0b（橙），背景#f8fafc，文字#1e293b
字体：标题用Inter Bold，正文用Inter Regular
间距：用8px网格，卡片内边距24px，卡片间距16px
圆角：卡片12px，按钮8px
阴影：卡片用0 4px 6px -1px rgba(0,0,0,0.1)
组件风格：参考shadcn/ui的现代简约风格
```

#### 步骤3：分组件做，不要一次做整页
- 先做导航栏，确认风格
- 再做Hero区域，确认配色和排版
- 再做卡片组件，确认间距和圆角
- 最后组合成完整页面
- 每个组件确认后再做下一个，避免整体返工

#### 步骤4：用具体的设计术语，不要用模糊词
| ❌ 模糊指令 | ✅ 具体指令 |
|------------|------------|
| "好看一点" | "把主色调成#2563eb，卡片圆角改成12px，加0 4px 12px rgba(0,0,0,0.08)的阴影" |
| "高级一点" | "用深色背景#0f172a，配金色文字#fbbf24，加细微的颗粒纹理，减少装饰元素" |
| "动效炫一点" | "卡片hover时上移4px，阴影加深，过渡0.3s ease-out；按钮点击时有scale(0.95)的反馈" |
| "布局乱" | "用CSS Grid，3列布局，gap 24px，卡片内边距32px，标题和正文间距16px" |
| "字太小" | "标题改成24px font-weight 700，正文16px line-height 1.6，辅助文字14px color #64748b" |

#### 步骤5：迭代优化，每次聚焦一个维度
- 第1次迭代：配色（只改颜色，其他不动）
- 第2次迭代：排版（只改字体大小、行高、间距）
- 第3次迭代：动效（只加hover、过渡、入场动画）
- 第4次迭代：细节（阴影、圆角、边框、图标）
- 不要一次改所有东西，否则不知道哪个改对了

### 两个GitHub神级项目（一键复刻）

#### 项目1：UI设计系统复刻
- **定位**：开源的高端UI设计系统，可直接clone使用
- **用途**：基于设计系统快速开发，保证风格统一
- **特点**：有完整的配色、字体、间距、组件规范
- **使用方法**：clone项目 → 看设计规范 → 基于组件开发

#### 项目2：VibeCoding模板集合
- **定位**：VibeCoding风格的开源模板
- **用途**：直接套用模板，或拆解学习
- **特点**：动效丰富，设计现代，代码完整
- **使用方法**：选一个喜欢的模板 → clone运行 → 修改内容和配色

## 第三层：替代思路（鼓励创新）

### 其他提升审美的方法
- **每天看10个Awwwards获奖网站**：培养审美直觉
- **拆解好的设计**：看到喜欢的界面，分析它的配色、字体、间距、动效
- **建立自己的设计素材库**：把喜欢的设计截图分类保存
- **学设计基础**：了解配色理论、排版原则、设计心理学
- **用AI做设计评审**：让AI分析你的设计哪里不好，怎么改

### 适用场景
- 用AI编程助手做网页/APP界面
- VibeCoding快速出稿
- 学习UI设计
- 提升个人审美

## 使用方法

1. **触发时机**：用AI编程助手做UI设计时
2. **操作步骤**：
   - 找3-5个参考设计
   - 给AI明确的设计系统（配色/字体/间距/组件风格）
   - 分组件开发，逐个确认
   - 用具体设计术语沟通，不用模糊词
   - 迭代优化，每次聚焦一个维度
3. **输入输出**：
   - 输入：参考设计、设计系统、具体需求
   - 输出：具有高级审美的UI界面代码
