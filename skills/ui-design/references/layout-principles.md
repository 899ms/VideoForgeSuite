# 布局设计原则

> 做UI设计和视频制作时的布局设计原则。核心是：有层次、有呼吸感、有规律，不是把元素堆在一起。

## 第一层：目标层（所有 agent 必须达成）

### 效果目标
布局有清晰的视觉层次，重要内容突出，次要内容弱化，元素之间有规律的间距，整体有呼吸感。

### 验收标准
- [ ] 有明确的视觉焦点（用户一眼知道看哪里）
- [ ] 元素大小有层次（标题>正文>辅助文字）
- [ ] 间距有规律（用8px网格，不是随机的）
- [ ] 有留白（不是满屏都是内容）
- [ ] 对齐统一（左对齐/居中/右对齐，不混乱）
- [ ] 分组清晰（相关元素靠近，不相关元素远离）
- [ ] 视频中内容不进入字幕安全区

### 禁止事项
- 禁止所有元素一样大（没有层次）
- 禁止间距随机（有的10px有的30px）
- 禁止满屏内容（没有留白）
- 禁止对齐混乱（一会左对齐一会居中）
- 禁止相关元素离得远（视觉分组不清晰）
- 禁止重要内容放在边缘或角落

## 第二层：实现层（参考，不强制）

### 核心设计原则

#### 1. 视觉层次（Visual Hierarchy）
通过大小、颜色、对比度、位置来区分内容的重要性：
- **最重要**：大尺寸、高对比度、强调色、居中/上方
- **次重要**：中等尺寸、中等对比度、辅助色
- **最不重要**：小尺寸、低对比度、中性色、边缘位置

**示例：**
```
Hero区域：
- 大标题：48px，加粗，主色，居中
- 副标题：24px，常规，辅助色，居中
- 正文：16px，常规，中性色，居中
- 按钮：20px，加粗，白色文字+强调色背景，居中
```

#### 2. 8px网格系统（8px Grid）
所有间距、尺寸都是8的倍数：
- 小间距：8px、16px
- 中间距：24px、32px
- 大间距：48px、64px
- 超大间距：96px、128px

**好处：**
- 间距有规律，看起来专业
- 不用每次想"这里该空多少"
- 响应式设计更容易

#### 3. 留白（Whitespace）
留白不是浪费空间，是设计的一部分：
- **微观留白**：文字行高、字间距、按钮内边距
- **宏观留白**：区块之间的间距、页面边缘的边距
- **功能留白**：把重要内容和其他内容分开，突出重点

**原则：**
- 内容越重要，周围留白越多
- 区块之间的留白 > 区块内部的留白
- 页面边缘的留白 > 内容之间的留白

#### 4. 对齐（Alignment）
- **左对齐**：最常用，适合大段文字、列表
- **居中对齐**：适合标题、按钮、短文本
- **右对齐**：适合数字、价格、日期
- **两端对齐**：适合书籍、报纸（网页少用）

**原则：**
- 一个区域只用一种对齐方式
- 所有元素都要和某个东西对齐（不要有"孤儿"元素）
- 不要随意居中（大段文字居中很难读）

#### 5.  proximity（接近性）
相关的元素靠近，不相关的元素远离：
- 标题和它的正文间距小（16px）
- 两个不同区块的间距大（48px+）
- 按钮和它的说明文字靠近
- 图片和它的图注靠近

**好处：**
- 用户不用思考"这个文字属于哪个标题"
- 视觉分组清晰，信息结构一目了然

#### 6. 重复（Repetition）
重复使用相同的设计元素：
- 所有按钮样式一样（圆角、颜色、阴影）
- 所有卡片样式一样（内边距、圆角、边框）
- 所有标题层级一样（H1都是48px加粗）
- 所有间距遵循8px网格

**好处：**
- 设计统一，看起来专业
- 用户学习成本低（知道这个样式的按钮可以点）
- 减少决策成本（不用每次想"这个按钮该什么样"）

### 常见布局模式

#### 1. F型布局（F-pattern）
用户浏览网页时的视线轨迹是F型：
- 先水平看顶部
- 然后往下，再水平看
- 然后继续往下看左边

**适用：** 内容密集的页面、文章、搜索结果
**设计要点：** 重要内容放在左上角和顶部

#### 2. Z型布局（Z-pattern）
用户视线从左上→右上→左下→右下，形成Z型：
- 先看左上角（Logo/标题）
- 然后水平看右上角（导航/按钮）
- 然后对角线到左下角（正文/图片）
- 最后到右下角（CTA按钮）

**适用：** 落地页、首页、简单页面
**设计要点：** CTA按钮放在右下角

#### 3. 单栏布局（Single Column）
所有内容在一列中，从上到下：
- 导航栏
- Hero区域
- 功能介绍
- 客户评价
- CTA
- 页脚

**适用：** 落地页、个人网站、简单产品
**优点：** 简单、清晰、移动端友好

#### 4. 双栏布局（Two Column）
左右两栏：
- 左栏：导航/菜单/目录
- 右栏：主要内容

**适用：** 文档、后台系统、博客
**优点：** 导航清晰，内容空间大

#### 5. 网格布局（Grid / Bento）
用CSS Grid把页面分成多个大小不一的卡片：
- 大卡片：重要内容
- 小卡片：次要内容
- 卡片之间有统一的间距

**适用：** 仪表盘、作品集、内容平台
**优点：** 信息密度高，视觉丰富

### 视频中的布局注意事项

#### 字幕安全区
- 横版（1920x1080）：字幕带在 y=880 到 y=1020 之间
- 重要内容不要进入字幕安全区
- 标题、图表、角色都要在安全区内

#### 三分法构图
把画面分成3x3的网格，重要元素放在交叉点上：
- 不要把主体放在正中间（太死板）
- 放在左上/右上/左下/右下的交叉点
- 视线方向留出空间（角色看左边，左边多留白）

#### 视觉引导
用元素引导观众的视线：
- 箭头指向重要内容
- 角色手指向重要内容
- 线条汇聚到重要内容
- 颜色对比突出重要内容

## 第三层：替代思路（鼓励创新）

### 其他布局方法
- **不对称布局**：打破对称，更有创意（但要保持平衡）
- **全屏布局**：每个区块占满全屏，滚动切换
- **杂志风布局**：像杂志一样，图文混排，大小不一
- **实验性布局**：打破常规，适合创意网站

### 适用场景
- 快速出稿 → 用常见布局模式（单栏/双栏/网格）
- 创意网站 → 不对称/全屏/杂志风
- 视频制作 → 三分法构图+视觉引导+字幕安全区

## 使用方法

1. **触发时机**：做UI设计或视频制作，需要布局时
2. **操作步骤：**
   - 确定内容的重要性排序（什么最重要，什么次重要）
   - 选择合适的布局模式（单栏/双栏/网格/F型/Z型）
   - 用8px网格设置间距
   - 应用视觉层次（大小/颜色/对比度/位置）
   - 检查对齐和分组
   - 确保有足够的留白
   - 视频中检查字幕安全区和三分法构图
3. **输入输出：**
   - 输入：内容结构、重要性排序
   - 输出：清晰、有层次、有呼吸感的布局
