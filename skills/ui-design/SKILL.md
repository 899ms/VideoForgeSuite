## 📝 使用说明

### 做UI设计时的调用顺序
1. 先看[[AI编程助手UI审美提升指南]]，确定方法论
2. 从[[配色方案库]]选一套配色
3. 用[[布局设计原则]]确定布局
4. 从[[UI组件]]分类选需要的组件
5. 从[[动效模式]]分类选需要的动效
6. 参考[[VibeCoding宝藏网站合集]]找灵感和现成资源

### 做视频时的调用顺序
1. 先看[[视频制作大师SKILL]]，确定工作流
2. 从[[解说视频视觉风格库]]选视频风格
3. 从[[配色方案库]]选配色
4. 用[[布局设计原则]]确定画面构图
5. 从[[动效模式]]分类选画面动效
6. 需要HTML背景时用[[环星呼吸粒子动效工作台]]

### 组合示例
- **高端科技官网**：配色方案库(科技蓝) + 布局设计原则(单栏) + 动效模式(3D倾斜+视差滚动) + VibeCoding资源(模板)
- **科普视频**：视频制作大师 + 解说视频风格库(Kurzgesagt/扁平宇宙) + 配色方案库(Kurzgesagt风格) + 布局设计原则(三分法) + 动效模式(路径绘制+交错入场)
- **VibeCoding快速出稿**：AI编程助手审美指南 + VibeCoding宝藏网站(参考+模板) + 配色方案库 + 动效模式(环星呼吸粒子)
