# 三旋钮详解 · Dials

三旋钮不是感觉，是参数。开工前定数值，制作中回看，交付前对照。

## DENSITY 画面密度

| 档位 | 规则 |
|---|---|
| 1-3 | 一屏一个主体，留白 ≥50%，信息靠口播带 |
| 4-6 | 一屏 1 主体 + 2-3 辅助元素（标签/角标/进度指示） |
| 7-10 | 高信息流：主体 + 数据层 + 氛围层（粒子/网格/光效）同时存在 |

密度红线：
- 低密度片最怕"静态图+长口播"——必须给主体加微动效（呼吸/漂浮/光扫）
- 高密度片最怕互相打架——主体永远唯一，辅助元素透明度 ≤80%
- 每 8 秒窗口内必须有画面变化（切换/运镜/动效入场），否则插入 B-roll 或运镜

## MOTION 动效强度

| 档位 | 允许的动效词汇 |
|---|---|
| 1-3 | fade / 位移 8-20px / 缩放 1.0→1.05 |
| 4-6 | + stagger 层叠入场 / 手绘描线 / 数字滚动 / 高亮扫过 |
| 7-10 | + 弹性物理（过冲回弹）/ 粒子爆发 / 2.5D 运镜 / 转场特效全套 |

强度红线：
- 同级词汇单镜头内 ≤2 种；高强度 ≠ 堆料，是节奏快
- 特效全片去重：同一特效最多出现 2 次，第 3 次必须换（防审 judge 重复+观众腻）
- 强度要跟段落功能走：hook 段最高，讲解段中等，CTA 段再拉高

## EXPERIMENT 风格实验度

- 1-3：直接用素材库现成风格模板，保证下限
- 4-6：模板为主，每支片尝试 1 个新招（新转场/新字幕样式/新构图）
- 7-10：跨风格嫁接（手绘×HUD、孟菲斯×纪录片段落），只在自己能兜底时用

> 防同质化规则：同一风格连续 3-4 条片后必须换向。工作台的"流行风格样板"分类就是为此准备的换装库。
