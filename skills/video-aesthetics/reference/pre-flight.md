# 交付前自审矩阵 · Pre-Flight

成片不等于完成。以下矩阵全绿才算完成。**自审不过关就交，等于把审稿人的活甩给观众。**

## 1. 抽帧检查（≥8 帧）

抽帧时刻：首帧 / 开场结束 / 每段中点 / 每段结尾 / 随机 3 帧 / 尾帧。

每帧回答 5 个问题：
- [ ] 有没有元素被遮挡？（字幕压字、贴片压脸、徽章压 UI 数据）
- [ ] 有没有元素被裁切？（该完整的元素出框/出血）
- [ ] 字幕有没有重叠、超行、错别字？
- [ ] 画面有没有空白空窗期（动画还没进场的空帧）？
- [ ] 风格还统一吗？（把 3 帧并排看，像同一条片吗）

## 2. 动态检查（抽 3 段各 10s 看）

- [ ] 任意 8s 窗口内有画面变化（无静止长图）
- [ ] 运镜有缓动有终点（无匀速直线漂移）
- [ ] 特效使用次数台账：同款 ≤2 次

## 3. 遮挡专项（重点，出过事故）

- [ ] 叠加元素（字幕/贴片/徽章/弹窗）与画面主体间距 ≥48px
- [ ] 抖音安全区：右下角互动列、底部文案区、顶部悬浮区无关键内容
- [ ] 弹窗/弹幕类元素检查出现期间是否盖住讲到的内容
- [ ] 用 25% 透明度蒙版模拟叠加层，确认被遮挡区域可接受

## 4. 听觉检查

- [ ] 全片听一遍：无爆音/咔哒声（拼接点 in/out 各留 60ms 淡入淡出）
- [ ] BGM 不压人声（讲解段 BGM ≤ -22dB）
- [ ] SFX 与画面事件对位（误差 ≤2 帧）
- [ ] TTS 语速与字幕消失速度匹配（字幕不闪没）

## 5. 平台合规

- [ ] 无网址 / 二维码 / 引导第三方平台的画面与口播
- [ ] 无重复内容超阈值（同素材占比）
- [ ] 时长符合目标（中长视频无注水段落）
- [ ] 首帧即有信息量（封面可截）

## 6. 他人视角

- [ ] 交给"第一次看的人"检查：能看懂教的东西吗？哪里划走？

> 自审发现的任何一条不通过 → 定位 → 修复 → 重新抽帧该时刻 ±3s，不必全片重审。
