# 风格库 · Styles（对应工作台素材库）

一条片锁一个方向。每个风格给出：适用题材 / 配色规律 / 字体气质 / 运动特征 / 素材库入口。

## 选用规则

1. 先查"风格连用记录"：同一风格 3-4 条片内用过 → 必须换向
2. 题材定大类：热血→暗色系，干货→手绘系，种草→孟菲斯系
3. 一个方向内可以混 2 种近亲风格（如 Vox+手绘），不可跨系混搭（赛博朋克×剪纸=灾难）
4. 选定后，该风格在素材库的所有子分类都算"同方向资源"，跨分类点单算混搭

## 记忆点设计

每条片设计 1 个可复用视觉符号（观众刷到下期能认出来）：
- 固定吉祥物（小黑豆/哈士奇）在固定位置吐槽
- 固定开场动作（图章盖章 / 翻牌 / 手绘开场）
- 固定收尾版式（同色同布局，只换文字）
