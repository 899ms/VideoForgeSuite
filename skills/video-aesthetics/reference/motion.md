# 动效纪律 · Motion Craft

## 硬性性能规则

- 只动画 `transform`（translate/scale/rotate）和 `opacity`——GPU 合成层，稳 60fps
- 禁止动画 `width/height/top/left/margin`——每帧重排，必掉帧
- filter（blur/saturate）谨慎用：大面积高斯模糊 + 每帧变化 = 手机发烫
- 视频没有 `prefers-reduced-motion`，但有"观看疲劳"：连续高强度动效 20s 后观众划走率上升，必须给呼吸段

## 时长档位（不要发明第 6 档）

| 档位 | 用途 |
|---|---|
| 120ms | 微反馈：角标闪烁、下划线扫入 |
| 200ms | 标准入场：卡片、标签、字幕块 |
| 300ms | 转场、面板切换、数字滚动 |
| 450ms | 大动作：全屏元素、2.5D 运镜落位 |
| 800ms+ | 只给开场定调和收尾定格，全片 ≤2 次 |

## 缓动词汇表（把感觉翻译成参数）

| 客户/自己说 | 参数 |
|---|---|
| "有点硬""太突然" | `cubic-bezier(0.22, 1, 0.36, 1)`（标准减速） |
| "要弹一下" | 回弹：目标值过冲 3-6% 再回收 5f（如 1→1.04→1.02→1） |
| "要重一点""砸" | ease-in 急加速 + 到位震屏（amp 14px、τ≈1.8f、6f 收干） |
| "温柔一点" | `cubic-bezier(0.4, 0, 0.2, 1)` + 时长升一档 |
| "要跟手" | 位移差分驱动：速度越快形变越大（拉伸/拖尾） |

## 节奏与配对

- **入场/退场配对**：从右侧滑入的，退场回右侧；观众潜意识里有空间感
- **层叠 stagger**：多个元素入场间距 60-90ms，方向统一；超过 5 个元素改分组入场
- **hold 才是高级感**：每个动效落位后 hold ≥30f 让观众读完信息；高手和新手的差距在 hold 不在动
- **卡点**：重拍（鼓点/重音）对齐剪辑切换，误差 ≤2 帧；BGM 先拆节拍再做时间轴

## 数字人/口播特殊规则

- 口型速度宁慢勿快，快了像抽搐
- 表情克制：微呼吸 + 小幅度头动即可，禁止瞪眼挑眉
- 静态立绘口播时，画面其他层（背景/字幕/组件）承担动感，立绘本身只做微呼吸
