# 视频制作大师 SKILL（可进化版）

> 这不是一个静态清单，是一个**活的技能系统**。每次做完视频都要复盘，把新经验加入 `evolve_log`。
> 核心原则：**先理解再呈现，先规划再制作，每步有检查，做完必复盘。**

---

## 第一部分：审美判断标准（什么是好，什么是AI味）

### ✅ 好的设计（大师级）

| 维度 | 标准 | 反面（AI味） |
|------|------|-------------|
| **配色** | 3-4色：1主色+1辅助色+1中性背景色；同色系深浅变化；冷暖对比有节奏 | 渐变文字、发光边框、毛玻璃、霓虹色混搭、彩虹色 |
| **布局** | 一个视觉焦点；留白充足；元素有大小层级；重要内容居中放大 | 满屏元素、所有东西一样大、没有呼吸感、卡片堆卡片 |
| **动画** | 每个动画有目的（引导视线/强调重点/解释逻辑）；缓动自然；节奏有快慢变化 | 为动而动、所有元素同时动、匀速运动、只有放大缩小 |
| **角色** | 有表情变化、有肢体动作、和场景互动、有性格 | 站着不动的火柴人、没有表情、和场景脱节 |
| **信息** | 一个场景讲一个点；数据直接标注；重要数字出现时背景简化 | 一个场景塞10个概念、图例在角落要观众自己找、背景比内容还花哨 |
| **节奏** | 每5-8秒一个信息点；画面静止不超3秒；有快有慢有停顿 | 前5秒放完所有东西后面全静止、或者从头到尾匀速没有变化 |

### 🚫 绝对禁止的AI味元素

- 渐变文字（gradient text）
- 发光边框（glow border）
- 毛玻璃（backdrop-filter blur）
- 霓虹色混搭（neon color mix）
- 粒子星云背景（particle nebula background）
- 呼吸光晕动画（breathing glow animation）
- 旋转环星装饰（rotating ring decoration）
- 所有元素同时出现（all elements appear at once）
- 放大缩小当唯一动画（zoom as the only animation）

## 第二部分：7阶段工作流（大师级流程）

> 参考：Kurzgesagt制作流程 + animated-explainer-skills 7阶段法

### 阶段1：脚本与深度理解

**做什么：**
1. 写脚本（黄金7段式：钩子→为什么重要→核心概念→拆解细节→真实例子→局限→总结行动）
2. 逐句标注（🔴核心概念/🔵数据对比/🟢流程步骤/🟡例子场景/🟣金句总结/⚪过渡句）
3. 确定每个场景的**单一核心洞察**（one core insight per scene）

**检查清单：**
- [ ] 3秒内有钩子
- [ ] 每5-8秒一个信息点
- [ ] 每个场景只有一个核心点
- [ ] 用大白话，专业术语都有解释
- [ ] 总字数：每分钟220-250字（中文口播语速）

### 阶段2：风格帧设计（Styleframe）

**做什么：**
1. 从[[解说视频视觉风格库]]选风格（8种：乐高写实/Vox纸片拼贴/火柴人/黏土定格/毛毡织物/剪纸定格/扁平宇宙/工程蓝图）
2. 确定配色方案（3-4色，参考[[配色方案库]]）
3. 设计角色（参考[[角色设计规范]]）
4. 画每个场景的静态风格帧（不做动画，先确定画面长什么样）

**检查清单：**
- [ ] 风格和内容匹配（技术类→工程蓝图/扁平宇宙，科普类→乐高/Vox/火柴人）
- [ ] 配色不超过4种
- [ ] 角色有辨识度、有性格
- [ ] 每个场景的静态帧就已经好看（动画是加分，不是救命）
- [ ] 没有AI味元素

### 阶段3：素材生成与组织

**做什么：**
1. 生成角色SVG（带动作变体：思考/打字/走路/指方向/困惑/开心）
2. 生成图标/道具SVG
3. 生成背景场景SVG
4. 需要生图的场景（CSS做不到的复杂场景）用生图工具
5. 所有素材按 `characters/` `icons/` `backgrounds/` `images/` 分类存放

**素材融入机制（以后新素材怎么进来）：**
```
新素材来源：
  ├─ 用户发的抖音链接 → 提取视频中的动效/风格/配色 → 归入对应分类
  ├─ 用户发的网站链接 → 分析网站的UI组件/动效/布局 → 归入对应分类
  ├─ 用户要求复刻的设计 → 拆解复刻对象的元素/配色/动效 → 归入对应分类
  └─ 制作过程中自创的好素材 → 提炼成可复用组件 → 归入对应分类

分类体系：
  ├─ 视觉风格（8种 + 新增）
  ├─ 配色方案（每套3-4色 + 适用场景）
  ├─ 角色设计（每个角色带动作库）
  ├─ UI组件（卡片/按钮/侧边栏/轮播/特殊控件）
  ├─ 动效模式（入场/持续/交互/转场/运镜）
  ├─ 信息图模板（知识树/流程图/对比表/数据图表）
  └─ 场景模板（办公室/教室/数据中心/抽象空间）
```

### 阶段4：动画编排（Choreography）

**做什么：**
1. 写分镜表（每个镜头：时间/口播/画面/动效/配色/运镜）
2. 动画和口播精确对齐（说到哪，哪出现）
3. 用GSAP做动画（所有高级插件免费：DrawSVG/MorphSVG/SplitText/Physics2D/MotionPath/Flip/CustomEase）

**核心动效模式库（必须会用，不止呼吸浮动旋转粒子）：**

| 类别 | 动效 | 适用场景 | GSAP实现 |
|------|------|---------|---------|
| **入场** | 交错入场(stagger) | 列表/卡片/步骤 | `stagger: 0.1` |
| | 路径绘制(draw) | 知识树/流程图/箭头 | DrawSVG插件 |
| | 弹性入场(back.out) | 重点元素/图标 | `ease: "back.out(1.7)"` |
| | 滑入(slide) | 标题/面板/分屏 | `x: -100 → 0` |
| | 打字机(typewriter) | 对话/代码/终端 | SplitText插件 |
| | 数字滚动(count-up) | 数据/统计 | `{value: 0 → target}` |
| **持续** | 挤压拉伸(squash-stretch) | 角色跳跃/物体落地 | CustomBounce |
| | 物理碎片(physics-debris) | 爆炸/分解/转换 | Physics2D插件 |
| | 形态融合(morph) | 概念转换（A变成B） | MorphSVG插件 |
| | 视差分层(parallax) | 空间深度/场景推进 | 3层不同速度 |
| | 角色动作(character-rig) | 角色走路/打字/思考 | 关节绑定+关键帧 |
| **交互** | 3D倾斜(tilt) | 卡片/产品展示 | `rotateX/rotateY` |
| | 磁吸跟随(magnetic) | 按钮/图标 | 鼠标位置*系数 |
| | 手风琴展开(accordion) | 图片画廊/菜单 | `flex: 1 → 4` |
| | Bento网格拼贴 | 作品集/内容平台 | CSS Grid span |
| **转场** | 擦除切换(wipe) | 场景切换 | `clip-path` 动画 |
| | 缩放转场(zoom) | 宏观→微观 | `scale: 1 → 2` |
| | 元素转场(element) | 角色贯穿视频 | 角色从A走到B |
| **运镜** | 推近(push-in) | 强调细节/核心概念 | `scale: 1 → 1.2` |
| | 拉远(pull-out) | 总结/展示全局 | `scale: 1.2 → 1` |
| | 平移(pan) | 并列元素/流程 | `x: 0 → ±200` |
| | 跟随(follow) | 角色做事 | 相机跟随角色 |

**Kurzgesagt标志性动效（必须掌握）：**
1. **Fuse动效**：N个物体 morph 变成它们代表的概念（"same objects, new shape"）
2. **人口即角色**：数量用小人物表示，不是圆点
3. **飞行主持人**：吉祥物会指、会敲、会跳、会反应
4. **挤压拉伸**：落地时的 squash 就是重量感
5. **分层视差**：3层深度，相机推拉时有空间感

**动画节奏铁律：**
- 说到哪个概念，哪个元素出现（口播同步）
- 多个元素用交错入场，不是同时出现
- 画面静止不超过3秒（持续有微动）
- 重要数字出现时，背景简化（"杀掉背景"）
- 基础概念慢，例子快，有 strategic pause 给观众思考

### 阶段5：留存率优化（Retention Pass）

**做什么（3轮审计）：**
1. **钩子/峰值循环审计**：前3秒有没有钩子？每30秒有没有一个小高潮？
2. **死区清除**：用节拍审计器检查每个场景的最后一个动效时间，覆盖率，超过4秒的间隙
3. **VO同步验证**：逐句检查口播和画面是否同步

**检查清单：**
- [ ] 前3秒有钩子（反常识/痛点/惊人数据）
- [ ] 每30秒有一个视觉小高潮
- [ ] 没有超过4秒的"死区"（没有任何动效变化）
- [ ] 口播和画面逐句同步
- [ ] 结尾有行动号召（点赞关注/下集预告）

### 阶段6：质量检查门（Gates）

**做什么（3个审计器）：**

1. **重叠审计器（0.5秒分辨率）**：
   - 检查"文字压文字"
   - 检查主持人撞标题
   - 检查元素超出安全区
   - 实现：遍历每个时间点（0.5秒步长），检测所有可见元素的边界框重叠

2. **节拍审计器**：
   - 每个场景的最后一个动效时间
   - 动效覆盖率（%）
   - 超过4秒的间隙
   - 实现：解析GSAP timeline，统计每个时间点是否有动效在进行

3. **冻结帧验证**：
   - 在每个场景的开始、中间、结束各截一帧
   - 人工检查：这一帧单独看好不好看？
   - 如果冻结帧不好看，动画也救不回来

**检查清单：**
- [ ] 0.5秒分辨率重叠审计通过（无文字压文字、无角色撞标题）
- [ ] 节拍审计通过（无超过4秒死区）
- [ ] 每个场景的冻结帧都好看
- [ ] 所有元素在字幕安全区内（横版：y<880 或 y>1020 是字幕带）
- [ ] 视频清晰不模糊
- [ ] 音频和画面同步

### 阶段7：配音合成与发布

**做什么：**
1. 按场景生成配音（每场景一个clip，2.5词/秒）
2. 自动报告哪些场景配音超时，延长对应场景
3. 合成配音和视频
4. 加背景音乐（音量低于人声，不抢戏）
5. 加字幕（可选）
6. 导出最终视频

**检查清单：**
- [ ] 配音清晰，语速合适
- [ ] 背景音乐不抢人声
- [ ] 字幕和口播同步（如果有字幕）
- [ ] 视频时长符合预期
- [ ] 文件大小合理

## 第四部分：自我进化机制

### 每次做完视频后的复盘流程

1. **提取视频帧**：每个场景的开始、中间、结束各截一帧
2. **人工检查**：
   - 这一帧好不好看？
   - 有没有AI味元素？
   - 布局有没有问题？
   - 配色舒服吗？
3. **动画检查**：
   - 有没有超过3秒的静止？
   - 口播和画面对齐了吗？
   - 动效有没有目的？
4. **总结经验**：
   - 哪些做得好？（加入 `evolve_log` 的"成功经验"）
   - 哪些做得不好？（加入 `evolve_log` 的"失败教训"）
   - 发现了什么新动效/新配色/新布局？（加入素材库）
5. **更新skill**：把新经验写入这个文件的 `evolve_log`

### evolve_log 格式

```yaml
- date: 2026-08-30
  video: "AI Agent是什么"
  success:
    - "用办公室场景+实习生角色，观众有代入感"
    - "路径绘制动画做知识树，逻辑清晰"
  failure:
    - "前6秒放完所有元素，后面静止（违反'画面静止不超3秒'）"
    - "小人就是火柴人，没有表情变化（违反'角色有表情有动作'）"
    - "配色用了米黄+红+深蓝，不柔和（AI味）"
  new_asset:
    - "实习生角色SVG（带6种动作）"
    - "办公室场景模板"
  improvement:
    - "下次：动画和口播逐句对齐"
    - "下次：角色至少有3种表情变化"
    - "下次：配色从配色方案库选，不自己瞎搭"
```

## 第五部分：新素材融入SOP（用户发链接后怎么做）

当用户发一个抖音链接/网站链接/要求复刻某个设计时：

1. **提取内容**：
   - 抖音链接：用视频提取工具获取视频内容，分析其中的动效/风格/配色/布局
   - 网站链接：分析网站的UI组件/交互动效/配色方案/排版布局
   - 复刻要求：拆解复刻对象的每个元素、配色、动效、布局

2. **分类归入**：
   - 是新的视觉风格？→ 加入 `视觉风格/`
   - 是新的配色？→ 加入 `配色方案/`
   - 是新的角色？→ 加入 `角色设计/`
   - 是新的UI组件？→ 加入 `UI组件/`
   - 是新的动效？→ 加入 `动效模式/`
   - 是新的信息图模板？→ 加入 `信息图模板/`
   - 是新的场景？→ 加入 `场景模板/`

3. **写使用说明**：每个新素材都要写清楚：
   - 它是什么
   - 什么时候用它
   - 怎么用（代码示例/实现方式）
   - 和其他素材怎么搭配

4. **验证效果**：在一个测试场景中用一下这个新素材，确认效果好，再正式加入素材库
